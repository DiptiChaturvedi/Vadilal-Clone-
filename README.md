# Vadilal Website Clone 🍦

A simple and responsive frontend clone of the official Vadilal Ice Creams website. This project was built to practice and improve web development skills.

## 🚀 Features

* Clean and attractive User Interface (UI) similar to the original website.
* Responsive design (Mobile and Desktop friendly).
* Smooth hover effects and CSS animations.

## 🛠️ Technologies Used

* **HTML5**: For the structure of the web pages.
* **CSS3 with Bootstrap**: For styling, layout, and animations.
